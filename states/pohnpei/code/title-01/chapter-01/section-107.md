§1-107. Citation of Code. 

(1) Sections of the Code may be cited by the abbreviation “PC”, preceded by the title number and succeeded by the chapter number, a dash, and the section number. For example, this section would be cited as “1 PC 1-107”, representing Section 107 of Chapter 1 of Title 1 of the Official Code of the State of Pohnpei.

(2) Unless the context clearly requires otherwise, any reference in this Code or in any law, rule or regulation of this state to a provision of the Code shall be construed to refer to the Code as it now or hereafter exists.

Source: S.L. No. 6L-79-06 §1-107, 11/1/06
