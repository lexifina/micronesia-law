§1-110. Severability of provisions of the Code. Except as otherwise specifically provided in this Code, in the event any title, chapter, subchapter, part, section, subsection, paragraph, subparagraph, item, sentence, clause, phrase, or word of this Code is declared or adjudged to be unconstitutional, such declaration or adjudication shall not affect the remaining portions of the Code which shall remain in full force and effect as if the portion so declared or adjudged invalid or unconstitutional was not originally a part of this Code.

Source: S.L. No. 6L-79-06 §1-110, 11/1/06
