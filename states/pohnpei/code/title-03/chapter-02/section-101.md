§2-101. Prohibition against the Governor and the Lieutenant Governor from being temporarily absent from the state at the same time.  Except where absence is necessitated by medical referral which can be supported by the testimony of a licensed physician, it is prohibited for the Governor and the Lieutenant Governor to be absent from the state of Pohnpei at the same time.

Source: S.L. No. 5L-14-00 §1-2A, 10/1/00
