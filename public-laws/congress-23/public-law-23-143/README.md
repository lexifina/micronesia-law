# Public Law No. 23-143: To enact title 44 of the Code of the Federated States of Micronesia entitled the Office of the Independent Prosecutor, to establish the Office of the Independent Prosecutor under title 44 of the Code of the Federated States of Micronesia (Annotated), to set the authority of the Independent Prosecutor and the Independent Prosecutor’s investigation and prosecution powers, to set the salary and qualifications for the Independent Prosecutor, to prescribe the penalties for failure to obey a lawful subpoena issued by the Independent prosecutor, to set the Office budget transmission and annual report requirements, and for other purposes.
