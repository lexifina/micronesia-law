§ 108. Trochus - Definition.

For the purpose of this chapter, the term trochus shall be considered Trochus niloticus. The names of Trochus maximus, Tectus niloticus, and Tectus maximus shall be considered names synonymous with Trochus niloticus .

Source: TT Code 1966 § 770 (part); TT Code 1970, 45 TTC 51(2); TT Code 1980, 45 TTC 51(2).
