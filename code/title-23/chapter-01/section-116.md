§ 116. General penalties.

A person violating any of the provisions of this title for which a different penalty is not otherwise provided shall upon conviction thereof be imprisoned for a period not exceeding six months, or fined not more than $100, or both.

Source: TT Code 1966, §§ 774, 784; TT Code 1970, 45 TTC 5; COM PL 4C-35 § 6; TT Code 1980, 45 TTC 5; PL 4-71 § 2.
