§ 203. Procedure if absent defendant fails to appear or plead.

If an absent defendant does not appear or plead within the time allowed, the court may proceed as if the absent defendant had been served with process within the Trust Territory, but any adjudication shall, as regards the absent defendant without appearance, affect only the property or status which is the subject of the action.

Source: TT Code 1966 § 338; TT Code 1970, 6 TTC 53, TT Code 1980, 6 TTC 53.
