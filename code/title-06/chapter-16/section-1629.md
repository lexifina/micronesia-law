§ 1629. Divorce - Procurement or connivance as defense.

No divorce for the cause of adultery shall be granted where the offense has been committed by the procurement or with the connivance of the plaintiff.

Source: TT Code 1966 § 701; TT Code 1970, 39 TTC 204; TT Code 1980, 39 TTC 204.
