§ 106. Issuance of summons.

The Clerk of Court shall issue a summons which shall contain the names of the parties, a general description of the whole property, or a reference to the complaint for the description of the land, and a notice to the defendants to appear in the proceedings.

Source: TT Code 1966 § 1305(part); TT Code 1970, 10 TTC 53(1)(part); TT Code 1980, 10 TTC 53 (1)(part).
